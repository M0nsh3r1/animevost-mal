# animevost-mal

Userscript для [animevost.org](https://animevost.org): находит аниме на [MyAnimeList](https://myanimelist.net), даёт отмечать серии, статус и оценку прямо на странице тайтла и добавляет тёмные темы оформления.

*English: a Tampermonkey userscript for animevost.org that finds the matching title on MyAnimeList, lets you mark episodes / status / score right on the page, ticks watched episodes in the player tabs, and adds dark themes.*

## Возможности

- **Поиск на MAL одним кликом.** Название берётся из заголовка страницы, поиск идёт через официальный API MAL. Кандидаты показываются карточками (тип, год, число серий, оценка), подходящий по году и типу подсвечивается.
- **Отметка серий прямо на сайте.** Кнопка «✓ Серия N просмотрена» берёт номер из выбранной серии в плеере. Статус, оценка и счётчик серий сохраняются автоматически. На последней серии статус сам становится Completed.
- **Галочки на вкладках серий** над плеером для уже просмотренных серий.
- **Сдвиг нумерации** для сезонов, которые на animevost идут одной страницей (дунхуа и т. п.): можно задать вручную или посчитать по одной известной серии.
- **Темы оформления:** «Анимевост» (светлая), «MAL (тёмная)», «MAL Redesign», «Discord», «Discord (серая)». Тема может перекрашивать весь сайт или только панель.
- Рекламный баннер над плеером заменяется панелью скрипта.

## Установка

1. Установите менеджер скриптов, например [Tampermonkey](https://www.tampermonkey.net/). В новых версиях Chrome для него может понадобиться включить «Разрешить пользовательские скрипты» в настройках расширения.
2. Откройте [animevost-mal.user.js](https://raw.githubusercontent.com/M0nsh3r1/animevost-mal/main/animevost-mal.user.js). Tampermonkey предложит установить скрипт. Новые версии подтягиваются автоматически.

Поиск и ссылки на MAL работают сразу. Чтобы отмечать серии, нужно один раз подключить свой аккаунт MAL (ниже).

## Подключение аккаунта MAL

Скрипт использует официальный API MAL, поэтому нужно своё приложение (бесплатно, 5 минут):

1. Откройте <https://myanimelist.net/apiconfig> и нажмите **Create ID**.
2. Заполните форму:
   - **App Type:** `other` (тогда секрет не нужен);
   - **App Redirect URL:** `https://animevost.org/mal-auth` (точно так);
   - остальные поля любые (Non-Commercial, hobbyist).
3. Скопируйте **Client ID**.
4. На странице animevost откройте меню Tampermonkey → **MAL: ввести Client ID**.
5. Нажмите **Войти в MAL** на панели и разрешите доступ.

Если приложение уже создано с типом `web`, у него есть Client Secret. Тогда ещё введите его через меню **MAL: ввести Client Secret**.

> Client ID и секрет хранятся только в локальном хранилище Tampermonkey и в код не попадают. Никому их не показывайте.

## Как пользоваться

1. Откройте страницу тайтла. Под описанием появится панель MyAnimeList.
2. Выберите нужный вариант («Это оно») или вставьте ссылку на страницу MAL. Выбор запоминается для этой страницы.
3. Смотрите серию, затем нажмите «✓ Серия N просмотрена». Вкладка получит галочку.

### Сдвиг нумерации

Нужен, когда на animevost серии идут подряд, а на MAL это отдельные сезоны. **Сдвиг = сколько серий на animevost идёт ДО первой серии этого сезона на MAL.** Например, сезон на MAL начинается с 174-й серии animevost: сдвиг 173, серия 195 уйдёт на MAL как 22.

Проще посчитать автоматически: раскройте «Нумерация не совпадает с MAL?», введите номер текущей серии на MAL и нажмите «Посчитать сдвиг».

## Известные ограничения

- Тёмная тема сайта сделана по разметке страниц, без доступа к стилям сайта, поэтому на редких страницах возможны светлые фрагменты. Присылайте скриншоты в Issues.
- Плеер и панель «Использовать / Скачать» находятся во вложенном окне и остаются оранжевыми.
- Если вы не вошли в MAL, поиск идёт через [Jikan](https://jikan.moe) и может отставать на свежих тайтлах.
- Галочки считаются по числу просмотренных серий на MAL, а не по каждой серии отдельно.

## Если что-то не работает

| Симптом | Что делать |
| --- | --- |
| `invalid_client` при входе | Проверьте Client ID. Если у приложения тип `web`, введите ещё и Client Secret. Или создайте новое с типом `other`. |
| Окно логина MAL не пускает дальше | Redirect URL приложения должен быть ровно `https://animevost.org/mal-auth`. |
| Нужно войти заново | Меню Tampermonkey → **MAL: войти**. |
| Ничего не находит | Нажмите «Поиск на MAL» и вставьте ссылку на страницу вручную. |

## Приватность и отказ от ответственности

- Скрипт общается только с MyAnimeList (`api.myanimelist.net`, `myanimelist.net`) и Jikan (`api.jikan.moe`) и ничего никуда больше не отправляет.
- Токены доступа лежат в локальном хранилище Tampermonkey.
- Проект неофициальный, не связан с animevost и MyAnimeList. Скрипт не размещает и не распространяет видео, он только меняет интерфейс страницы у вас в браузере.
