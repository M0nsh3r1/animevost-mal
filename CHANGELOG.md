# Changelog

Версии указаны по полю `@version` в заголовке скрипта. Формат: [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [2.2] — 2026-11-18
### Добавлено
- Тема «Discord (серая)».
- В блоке нумерации: «серия в плеере сейчас — это серия № на MAL» и кнопка «Посчитать сдвиг».
- В заголовок скрипта добавлены `@updateURL`, `@downloadURL`, `@homepageURL`, `@supportURL` (автообновление из репозитория).
### Изменено
- В тёмных темах убраны оранжевые рамки в левой колонке, белая обводка у текста («Рабочее зеркало», «Категории»), перекрашена плашка «До выхода N серии» и заголовки блока комментариев.
- Поясняющий текст про сдвиг стал понятнее.

## [2.1] — 2026-11-18
### Добавлено
- Темы оформления: «Анимевост», «MAL (тёмная)», «MAL Redesign», «Discord». Переключатель в шапке панели, запоминается.
- Перекраска всего сайта в тёмных темах (можно выключить галочкой «весь сайт»).
- Галочки «✓» на вкладках просмотренных серий над плеером.
- Тема применяется до отрисовки страницы (без «мигания»).
### Изменено
- Скрипт не запускается во вложенных окнах (`@noframes`).

## [2.0] — 2026-11-18
### Добавлено
- Поиск через официальный API MAL (быстрее и точнее, чем Jikan); Jikan остаётся запасным вариантом.
- Автосохранение статуса, оценки и числа серий; кнопка «Сохранить» убрана.
- Кэш поиска и данных списка: повторное открытие страницы мгновенное.
- Панель вставляется на место рекламного баннера над плеером.
### Изменено
- «Сдвиг» спрятан в раскрывающийся блок «Нумерация не совпадает с MAL?».
- Новое оформление панели в цвет сайта, компактнее.

## [1.2] — 2026-11-18
### Добавлено
- Client Secret отправляется ещё и в заголовке `Authorization: Basic`.
- В сообщении об ошибке входа показывается диагностика (длина Client ID и наличие секрета, сами значения не раскрываются).

## [1.1] — 2026-11-18
### Добавлено
- Поддержка Client Secret для приложений MAL типа `web`.

## [1.0] — 2026-11-18
### Добавлено
- Первая версия: разбор названия со страницы animevost, поиск кандидатов через Jikan, ссылка на поиск MAL.
- Вход в MAL (OAuth2 + PKCE) и отметка серий, статуса и оценки.

> Версии до 2.2 в репозитории не сохранены, только описание изменений.
